01Color

Surfaces → borders → text → accent → status. Components reference semantic tokens only. Click any swatch to copy its CSS variable.

Surfaces step up by lightness, never skip

Borders separate, never decorate

Text body uses secondary, not pure white

Accent & selection one primary accent per view

Status only inside status components

  • 表面只升不跳：app → base → raised，弹窗用 raised，输入框用 inset，选中用 active。

05Rules

Compose every new surface from these rules; rules win over personal preference.

✓Do

  • Reference --surface-*, --fg-*, and --border-* tokens only.
  • One primary action per view; everything else secondary or ghost.
  • Use text levels from primary to quaternary; body uses secondary.
  • Radii, spacing, and type come from the scales defined in tokens.css.
  • Compose new pages from existing atoms; consider additions only after composing.

✕Don't

  • Don't hardcode hex colors or invent new ones.
  • Don't use the accent as a large background or decoration.
  • Don't use borders as decoration; borders separate.
  • Don't mix status colors with priority colors.
  • Don't add a button style or size for a single page.
